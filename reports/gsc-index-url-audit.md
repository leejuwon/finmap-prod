## Judgment Guide

- `OK_REDIRECT_INDEXABLE`: legacy URL redirects to a live indexable destination with matching canonical.
- `OK_REDIRECT_NOINDEX`: legacy URL redirects to a live destination that intentionally carries noindex.
- `OK_REDIRECT_CANONICAL_MISMATCH`: legacy URL redirects, but the final canonical is missing or differs from the final URL path.
- `OK_REDIRECT_TO_404`: legacy URL redirects, but the final destination still returns an error.
- `OK_NOINDEX`: page intentionally carries noindex,follow.
- `FIX_404`: URL still returns a 4xx/5xx-like failure and needs mapping or removal.
- `CHECK_CANONICAL`: canonical is missing or differs from the final URL; review whether it is intentional.
- `CHECK_CONTENT`: live indexable page; review content depth and internal links before requesting indexing.

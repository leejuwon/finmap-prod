## Verifier Changes

### `verify_post_publish_urls.js`

- Builds an explicit hreflang URL map from post frontmatter.
- Uses mapping-based expected hreflang for mapped URLs.
- Validates explicit hreflang target URL status, final URL, canonical self, and noindex state.
- Builds expected stale same-slug URLs from mapping and treats those inputs as PASS only when they return 404 and are absent from sitemaps.
- Keeps `hreflangEquivalent: false` opt-out URLs as self-only.
- Keeps normal same-slug pairs as inferred pairs.

### `verify_seo_channel_split.js`

- Adds DCA mapped KO/EN samples.
- Builds expected head hreflang from `hreflangAlternates`.
- Keeps how-much opt-out samples and `what-is-cagr` normal pair regression samples.

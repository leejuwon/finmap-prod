## Calculation Formula

- Monthly DSR limit = `annualIncome * dsrRate / 100 / 12`
- New mortgage capacity = `max(monthlyDsrLimit - existingMonthlyDebtPayment, 0)`
- Equal-payment factor = `r * (1 + r)^n / ((1 + r)^n - 1)`; if `r = 0`, use `1 / n`
- DSR loan capacity = `newMortgageMonthlyCapacity / monthlyPaymentFactor`
- DSR price limit = `dsrLoanCapacity / (ltvRate / 100)`
- LTV/cash price limit = `cashOnHand / (1 - ltvRate / 100 + extraCostRate / 100)`
- Final affordable price = `min(dsrPriceLimit, cashLtvPriceLimit)`
- Bottleneck = `DSR` when DSR price limit is lower; otherwise `CASH_LTV`

## Candidate Decision Rule

- `PASS`: DSR, LTV, and cash checks all pass.
- `WARNING`: at least one check fails, but the maximum shortfall ratio is greater than 0 and less than or equal to 5%.
- `FAIL`: any failed check has a maximum shortfall ratio greater than 5%.
- DSR shortfall = `max(candidateRequiredLoan - dsrLoanCapacity, 0) / max(candidateRequiredLoan, 1)`
- LTV shortfall = `max(candidateRequiredLoan - candidateMaxLoanByLtv, 0) / max(candidateRequiredLoan, 1)`
- Cash shortfall = `max(candidateCashRequirement - cashOnHand, 0) / max(candidateCashRequirement, 1)`

## Policy Scope

- No automatic policy update is applied.
- User-entered LTV and DSR values are used as-is.
- Repayment method is equal principal-and-interest monthly repayment only.
- Actual lender review may differ because income recognition, credit profile, existing debt, collateral type, region, guarantee conditions, and lender policy can vary.

## Input Validation

- `annualIncome > 0`
- `cashOnHand >= 0`
- `existingMonthlyDebtPayment >= 0`
- `annualRate >= 0 && annualRate < 30`
- `loanTermYears > 0 && loanTermYears <= 50`
- `ltvRate > 0 && ltvRate <= 100`
- `dsrRate > 0 && dsrRate <= 100`
- `extraCostRate >= 0 && extraCostRate <= 30`
- `targetHomePrice >= 0`
- Blank, `NaN`, and `Infinity` inputs are recorded in `validationErrors` and protected with safe numeric fallbacks.
